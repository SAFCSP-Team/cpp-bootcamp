# Keywords
Programming languages in general have some reserved words that have meanings for the language called **keywords**. For example, `int` is a keyword for identifying an integer.
Developers are not allowed to use these keywords for naming purposes.

## Concept
**Keywords** are some reserved words reserved by the language, and it has a meaning for the language itself.

Some C++ keyword examples,
| Keyword | Meaning |
|---------|---------|
| `const` | used for declaring a constant |
| `class` | used to tell C++ that we are creating a class |
| `for` | used to start a loop|

For extra C++ keywords, kindly visit [cppregerence.com](https://en.cppreference.com/w/cpp/keyword), or [Microsoft documentation](https://learn.microsoft.com/en-us/cpp/cpp/keywords-cpp?view=msvc-170).

## Example

```cpp 
using namespace std;

int main() {
  const int num = 7;
  
  return 0;
}
```
`using`, `namespace`, `const`, `int` and `return` are all keywords in C++.
