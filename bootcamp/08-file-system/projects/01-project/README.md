# File System

**Objective**
Understand that the text file can store only string data, and its human readable. Also, understand how to read/write on it.

**Concepts**

| Concept   |      Resources      |
|----------|:-------------:|

**Problem**
Make a program that stores the user gorcery list in a text file and read it.

**Implementation**
Create either array or list of gorcery list items. Then write the list to a text file. Then read the text file and print the list.
